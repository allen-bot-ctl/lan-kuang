# 栏况 0.1.0

第一版：在菜单栏上看内存、CPU 和电池。

- 菜单栏左边显示内存和 CPU，例如「13G 9%」，每 2 秒刷新。
- 鼠标悬停会弹出面板，只放三项：内存、CPU、启动盘磁盘。
- 菜单栏右边显示电池，充电中、接电但没在充、用电池三种状态和系统一致；电量 20% 及以下变红。可以在「系统设置 › 控制中心 › 电池」里关掉系统自带的电池图标。
- 右键菜单里有「检查更新…」，以后的新版本都可以在应用里直接升级。

首次打开：macOS 会提示无法验证开发者。打开「系统设置 › 隐私与安全性」，点「仍要打开」即可，之后不会再提示。

支持 Intel 和 Apple 芯片的 Mac（同一个安装包）。
