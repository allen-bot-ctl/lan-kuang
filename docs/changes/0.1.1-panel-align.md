# 栏况 v0.1.1 契约：面板对齐，加首次应用内升级实测

来源：mind 走查 v0.1.0 的 CI 截图（run 44455880995，full.png）。demo：不出，改动是静态布局，用下面的数值核对。

## 改动
1. 面板三行都在最左边配环形图，环的直径 14pt，线宽 2pt，填充比例分别是内存 %、CPU %、磁盘 %。颜色：已用部分用系统强调色，未用部分用次要分隔色。
2. 三行的结构统一为「环 · 8pt 间距 · 标签 · 弹性空白 · 数值」。三个标签的左缘在同一条 x 坐标上，三个数值的右缘也对齐，距面板右缘 12pt（这条不变）。
3. 修 CI 截图：`menubar.png` 和 `panel.png` 要按 backingScaleFactor 把点换算成像素再裁剪，裁出来必须有内容。

## 不变
面板宽 260pt、只有三行、刷新频率、菜单栏格式、电池项。

## 验收
- C1：XCTest 或布局测试量出三行标签的 minX 相等（误差 ≤0.5pt），三行数值的 maxX 相等。
- C2：CPU 环在 0% 时只显示底色，在 100% 时填满。
- C3：CI 产出的 `menubar.png`、`panel.png` 不是全黑（像素最大值 > 0），面板截图里能看到三个环。
- C4：最长文案 `3999 / 4000 G · 100%` 加上环以后，在 260pt 宽度里仍然不截断。
- C5：Release 有 dmg、zip、sha256、appcast.xml 四个附件，都返回 200；appcast 里最新一项是 0.1.1，说明是本版内容。
- C6（老板真机）：已装的 v0.1.0 通过「检查更新…」看到 v0.1.1 和本版说明，一键升级、自动重启，不需要手动重装，也不会再弹出 Gatekeeper 拦截；重启后两个菜单栏项都还在原来的位置。
