# 栏况 v0.1.8 契约：按本机真实最长值定宽，去掉右侧空白

来源：老板 2026-11-19 02:51 截图（`docs/changes/assets/0.1.8-before.png`）：0.1.7 后栏况和时钟的距离更大。
原因（mind 契约失误）：整项按 `128G/100%/↑999K` 定宽，16G 的 Mac 永远到不了，常见值 `13G/73%`、`↑9.5K/↓39K` 少将近两个字符，空白全在右边。

## 定宽规则（启动时算一次，之后不变）
- **内存/CPU 列**宽 = max(本机内存总量格式化后的宽度，如 `16G`；`99%`)。内存显示值不会超过总量位数。
- **CPU 最多显示 `99%`**（≥ 99.5% 显示 99%）。面板里照常显示真实值，可以是 100%。
- **网速列**宽 = 箭头 + 1pt + `205K` 的宽度（4 个字符）。格式规则不变：< 10 带一位小数（`9.5K`），≥ 10 取整（`39K`、`205K`），≥ 1000 进到下一个单位（`1.2M`）。所以这一列最多 4 个字符，空白最多 1 个字符。
- 左边距 2pt，右边距 2pt + 本次空出的宽度（只会是 0 到 1 个字符）。间距沿用 0.1.7：3pt / 3pt / 箭头到数字 1pt。

## 验收
- M1：XCTest：内存总量 16G → 内存列按 `16G` 定宽；64G → `64G`；128G → `128G`。CPU 99.6% → `99%`，100% → `99%`，菜单栏不出现 `100%`。
- M2：CI 用 16G 模拟输出 1x 和 2x 图，`13G/73%/↑9.5K/↓39K` 和 `16G/99%/↑205K/↓999K` 两组；日志打印整项宽（16G 时约 60pt，上限 64pt）和右侧空白（≤ 6pt）。
- M3（老板真机）：栏况到右边时钟的距离和其他图标之间差不多。
