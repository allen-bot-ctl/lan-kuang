## 宽度规则
- 内存/CPU 列、网速列都按**本次实际最宽那一行**定宽；间距沿用 0.1.7（3pt / 3pt / 箭头到数字 1pt），左右边距各 2pt。
- 防抖：算出的新宽度**变宽时马上撑开**；**变窄时要连续 10 秒都窄才收回**，收回到这 10 秒里的最大值。
- 网速列最窄按 `99K` 留宽（798e3eb），低速时不来回跳。
- 菜单栏 CPU 最多显示 `99%`（面板里照常显示 100%），这一列不会因为 100% 变宽。
- 数字是等宽数字，所以宽度只在字符数变化时才动（如 `9.5K`→`39K`、`99%`→`100%`）。
