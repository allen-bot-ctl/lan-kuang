# 栏况 0.1.19 契约：设置卡一次显示全部设置，不用滚动

需求：老板 2026-11-27 02:25 NY 实机反馈（设置卡的滚动条静止时隐藏，用户不知道下面还有内容）。PM 02:27 NY 定稿。基线 master de6334e（v0.1.18）。分支 `wip-0.1.19`。不出样稿：改动只是设置卡变高，CI 截图能说清。

## 问题
设置卡和总览卡一样高（约 148pt），但设置里有 5 行：开机自启动、CPU 警戒阈值、内存警戒阈值、版本、更新（检查更新），加上标题大约要 200pt。最后「版本」「更新」两行被藏在下面，macOS 默认静止时不显示滚动条，所以用户发现不了。

## 规则
1. 打开设置卡时，面板高度跟着设置内容变高，5 行全部显示，不出滚动条。
2. 点「‹ 返回」或按 Esc 回到总览，面板恢复原来的高度。总览和其他卡片之间翻页仍然一样高，不受影响。
3. 面板仍然从菜单栏项正下方向下展开，顶边位置不变，只改变高度。
4. 只有屏幕放不下设置内容的时候，才保留 ScrollView 兜底；这时内容没滚到底，底部加一条约 16pt 的渐隐和一个小「⌄」提示，滚到底就消失。
5. 0.1.18 的 Esc 规则、悬停和点击行为都不变。

## 验收
1. 单测：设置卡高度由内容决定，并且在屏幕放得下时不触发兜底滚动。
2. CI 截图：设置卡深色、浅色各一张，要能完整看到「检查更新」那一行，不被切掉；另截一张回到总览后的面板，高度和 0.1.18 一样。
3. 老板 Mac 实机走查：
   - 打开设置卡，5 行全部可见，不用滚；
   - 点「‹ 返回」或按 Esc，面板恢复原高度；
   - 总览和其他卡片之间翻页，高度不变。
