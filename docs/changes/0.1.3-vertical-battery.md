# 栏况 v0.1.3 契约：竖电池，去掉遮挡面板的 toolTip

来源：老板 2026-11-19 00:51 真机反馈（v0.1.2）：18×9 横电池在 100% 接电时完全看不出形状，要不要改成竖的。
样稿：`docs/changes/assets/0.1.3-vertical-battery.png`（2x，从左到右依次是：接电 100%、充电中 45%、用电池 62%、用电池 15%、最长文案、无电池）。

## 竖电池
- 本体 8×16pt，圆角 2pt，描边 1pt，用模板色、60% 不透明度。正极头 4×1.6pt，在本体顶部居中，间隔 0.3pt。
- 填充区距描边内缘 1pt（宽 5pt、最高 13pt），按电量**从下往上**填，圆角 1pt；电量 > 0 时填充高度至少 1pt。
- 接电（包括充电中和已接电源未充电）：在填充上叠一个 ⚡，外形约 3.8×10pt，居中。⚡ 用模板色实心绘制，外圈描一圈 1.4pt 的「挖空」边（用 `.clear` 混合模式，或者用 mask 实现），保证 100% 满格时 ⚡ 的轮廓仍然清楚。
- 用电池：不叠标记。用电池且电量 ≤ 20% 时，填充用 systemRed。
- **取消插头图案。**「充电中」和「已接电源」只在右键菜单第一行用文字区分。
- 没有电池的 Mac：不画电池，也不留间距（和 v0.1.2 一样）。

## 布局
- 电池 · 3pt 间距 · 两行文字（字体、字号、行高、定宽都和 v0.1.2 一样）。电池和两行文字在菜单栏里一起垂直居中。
- 整项总宽目标 ≤ 40pt，上限 44pt（v0.1.2 是 48pt）。

## 修复
- 删除菜单栏项上的 toolTip（v0.1.2 悬停时弹出「电池 100% · 已接电源」，正好盖住面板内存行的数值）。悬停只出面板。

## 验收
- V1：CI 用 `--debug-battery` 截出接电 100%、充电中 45%、用电池 62%、用电池 15%、无电池五张图，每张按 2x 渲染（截图时用 `NSScreen` 的 backingScaleFactor 或者离屏 2x 渲染），在接电 100% 那张里能看出 ⚡ 的轮廓。
- V2：`--debug-longest` 时测得整项宽度 ≤ 44pt，写进 CI 日志。
- V3：XCTest 覆盖：电量 0.5 时填充高度是 6.5pt；接电时 bolt=true，用电池时 bolt=false；用电池 20% 时是红色，21% 时不是。
- V4：代码里搜不到对 statusItem.button 设置的 toolTip；悬停截图里只有面板，没有系统提示框。
- V5（老板真机）：从 v0.1.2 在应用内升到 v0.1.3；在 Retina 屏上，100% 接电时能一眼认出是电池，以及上面的 ⚡。
