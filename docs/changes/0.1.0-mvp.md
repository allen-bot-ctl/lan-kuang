# 栏况 v0.1.0 MVP 契约

来源：老板 2026-11-18 22:49 需求；方案见 PROPOSAL.md。demo：不出（静态布局，下面的数值可以直接核对）。打包建议用 xcodegen 或 Xcode 工程，避免 SwiftPM 自拼 .app 时 Sparkle.framework 的嵌入和 rpath 出问题。

## 范围
菜单栏放两个独立项（系统状态、电池），悬停出 3 项面板，右键菜单，Sparkle 自更新，CI 出 universal 包。
不做：设置页、进程列表、网络、温度、历史曲线、Wi-Fi、外接磁盘。

## 菜单栏
- 左项文字为「{内存}G {CPU}%」，例如 `13G 9%`。
  - 内存：已用 = (internal − purgeable + wired + compressor) × 页大小，除以 1024³ 后四舍五入成整数。
  - CPU：两次 HOST_CPU_LOAD_INFO 采样的 tick 差，(user+system+nice)/总 tick，四舍五入成整数，范围 0–100。
  - 字体：系统菜单栏字号，`monospacedDigit`；从 0% 变到 100% 时，项的宽度不变（按最长文案 `128G 100%` 定宽）。
- 右项：电池图标加整数百分比，例如 `87%`。图标为模板图，按电量连续填充，深色和浅色菜单栏下都清楚。
  - 充电中叠 ⚡；接电但没在充（包括已充满、优化充电）叠插头；用电池时不叠标记。
  - 用电池且电量 ≤ 20% 时，填充改为红色（非模板色）。
  - 没有内部电池的 Mac 不创建这一项。
- 两项都能按住 ⌘ 拖动，位置由系统记住。

## 悬停面板（只悬停在左项上才出现）
- 鼠标进入左项后 300ms 内弹出，离开左项和面板后 300ms 内收起；点击左项也能切换显示和隐藏。
- 面板宽 260pt，从上到下三行：
  1. 内存 `13 / 16 G · 81%`
  2. CPU `9%`
  3. 磁盘 `412 / 994 G · 41%`，左边配一个环形图，按已用比例填充。磁盘只算启动盘，可用量取 volumeAvailableCapacityForImportantUsage。
- 每行：左边是标签（次要色），右边是数值（主色，等宽数字），数值和面板右缘之间留 12pt。最长文案 `128 / 128 G · 100%`、`3999 / 4000 G · 100%` 不能截断、不能换行。

## 刷新
- 菜单栏每 2s 刷新一次；面板打开时改为每 1s，关上就恢复。
- 磁盘在打开面板时读一次，之后每 60s 一次。电池靠系统电源事件推送，另加 60s 兜底。
- 系统睡眠或锁屏时停止定时器，唤醒后立刻刷新一次。
- 不启动任何外部命令（不用 vm_stat、pmset、top）。

## 右键菜单（左右两项都有）
`检查更新…` / `开机自启动`（勾选状态，用 SMAppService）/ 分隔线 / `退出栏况`

## 自动更新
- 用 Sparkle 2。feed 地址：`https://github.com/allen-bot-ctl/lan-kuang/releases/latest/download/appcast.xml`。
- 更新弹窗显示 `release-notes/v<ver>.md` 的内容；EdDSA 私钥放在 GitHub Secrets，公钥写入 Info.plist 的 SUPublicEDKey。
- 签名：ad-hoc，不开 Hardened Runtime，不做公证。

## 出包
- tag `v0.1.0` 触发 CI，产出 `LanKuang-0.1.0-mac-universal.dmg`、`.zip`、`.zip.sha256` 和 `appcast.xml`。
- Release 说明取自 `release-notes/v0.1.0.md`，必须先于 tag 推送。

## 验收
- C1：`lipo -archs` 结果同时含 arm64 和 x86_64；`codesign -dv` 显示 adhoc。
- C2：XCTest 覆盖格式化：内存 12.4→`12G`、12.5→`13G`、CPU 99.6→`100%`、电量 20% 用电池→红色、21%→不红。
- C3：XCTest 覆盖 CPU tick 差计算，两次采样相同时不除零，输出 `0%`。
- C4：菜单栏截图里左项是「数字G 数字%」，没有「GB」字样，也没有小数。
- C5：面板截图里只有内存、CPU、磁盘三行，最长文案不截断。
- C6：空闲 60s（面板关闭），进程常驻内存 ≤ 60MB（最小程序实测：M 芯片 38MB、Intel 15MB，加 Sparkle 和面板后留余量），CPU 均值 ≤ 0.5%；实测数字写进发版说明。
- C7：Release 有 dmg、zip、sha256、appcast.xml 四个附件，都返回 200；appcast 里的版本号是 0.1.0，说明是本版内容。
- C9：鼠标从左项斜向移进面板的途中面板不消失：离开左项后有 300ms 缓冲，进入面板就取消收起；离开面板 300ms 后才收起。用 XCTest 或 UI 测试模拟「离开左项 → 200ms 后进入面板」，面板仍显示。
- C10（老板真机）：两个菜单栏项都能按住 ⌘ 拖动，退出重开后位置不变（autosaveName）。
- C8（老板真机，v0.1.1 时验）：在应用内从 v0.1.0 更新到 v0.1.1，不需要手动重装，重启后两个菜单栏项都还在。
