# 栏况 v0.1.4 契约：菜单栏项「胖一点」

来源：老板 2026-11-19 01:22 真机反馈（v0.1.3）：缩到真实尺寸后元素全挤在一起，要胖一点。
mind 量了老板截图（2x）：电池 8×15、描边 1pt 且 60% 不透明，看着发虚；文字 9pt 窄体（condensed），行高 10，两行贴在一起；旁边系统图标高约 16pt、数字约 13pt，我们明显小一圈。
样稿：`docs/changes/assets/0.1.4-fatter.png`（2x，菜单栏 24pt 高）。

## 电池（只改尺寸和线重，填充、⚡、红色规则不变）
- 本体 10×15pt，圆角 2，**描边 1.5pt、100% 模板色**（去掉 60% 不透明）。正极头 4×1.8pt，圆角 0.6，间隔 0.4pt，总高 17.2pt。
- 填充区距描边内缘 1pt：宽 5pt、最高 10pt，从下往上，圆角 1。
- ⚡ 约 4×9pt，居中，挖空边保持 1pt。

## 文字
- 10pt semibold，**标准宽度（去掉 .condensed）**，等宽数字保留；行高 10.5pt（两行共 21pt）。
- 电池与文字间距 4pt；左右边距各 2pt。

## 宽度
- 目标 ≤ 44pt，上限 46pt（以 `128G / 100%` 实测，写进 CI 日志）。超了先把字号降到 9.5，不动电池。

## 验收
- W1：CI `--debug-battery` 五张 2x 图（接电 100%、充电 18%、电池 62%、电池 15%、无电池）+ `--debug-longest`，最长文案不截断。
- W2：CI 日志里整项宽度 ≤ 46pt，两行文字块高度 ≤ 22pt，在 24pt 菜单栏里上下不贴边。
- W3：XCTest 跟着新数值更新（电量 0.5 时填充高 5pt；20%/21% 红色边界不变）。
- W4（老板真机）：应用内从 v0.1.3 升到 v0.1.4；和旁边系统图标放一起，电池和两行数字不再显得挤、虚。
