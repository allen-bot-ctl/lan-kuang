# 栏况 v0.1.11 契约：面板圆角、网络图标、电池行

来源：老板 2026-11-19 03:51 截图。按小需求走：不出 demo，不拆小版本，一次做完。

## C1 圆角下的白色方角
- 现象：面板四角圆角外露出一层白色方形底（左下、右下最明显）。
- 做法：不再用 `effect.layer.cornerRadius` 裁切，改用 `NSVisualEffectView.maskImage`（10pt 圆角、可拉伸的遮罩图），显示后调用 `invalidateShadow()`，阴影跟着圆角走。
- 验收：深色和浅色模式、白色背景窗口上各截一张 2x 图，四个角外都看不到方形底或白边。

## C2 网络行加静态图标
- 网络行左边原来是空位，改成静态 SF Symbol `arrow.up.arrow.down`，和其他行的环同一个框（`PanelLayout.ringDiameter`），颜色用强调色，和环的进度色一致。
- 不做动画，不随网速变化。

## C3 新增第五行「电池」
- 加在「网络」下面，排在最后。
- 环显示电量；数值写成 `82% · 充电中`，状态文字沿用 `batteryStatusText`（充电中 / 已接电源 / 使用电池）。
- 没有电池的 Mac 不显示这一行，面板高度跟着变。
- 最长文案 `100% · 已接电源`，不得超过现在面板宽度。

## 验收
- M1：现有测试全过；补测试：有电池 5 行，没电池 4 行。
- M2：CI 出面板截图 1x 和 2x，深色、浅色各一张，`--debug-battery=charging,82` 与 `none` 各一张。
- M4（老板真机）：四角干净，网络行有图标，电池行数值和菜单栏一致。
