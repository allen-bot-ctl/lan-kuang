# 栏况 v0.1.14 契约：总览标题栏、设置卡片、精简右键菜单

来源：老板 2026-11-19 04:41。样稿 `assets/0.1.14-settings-demo.html`，截图 `assets/0.1.14-settings-2x.png`（总览、内存、设置）。
其余沿用 0.1.13（卡片、翻页、曲线、配色不变）。

## C1 总览加标题栏
- 总览第一行和其他卡片的标题行一样：左边是「总览」，13pt 半粗。右边是「设置」按钮，和栏历一样是图标加文字：SF Symbol `gearshape` 12pt，加「设置」12pt。按钮是 22pt 高的胶囊，左右内边距 9pt，底色白 8%，悬停时白 15%，鼠标是手型。
- 标题行下面空 6pt 再接现在的 5 行，最后一行下面也空 6pt 再接页码点。
- 所有卡片跟着加高到同一个高度（总览高 + 30pt）。内存和 CPU 的曲线区从 72pt 加高到 86pt，其余卡片仍然居中，不加内容。

## C2 设置卡片（隐藏卡片）
- 不算在翻页里，页码点不变（有电池 6 个，没电池 5 个）。打开设置卡时页码点隐藏，滚轮和触摸板不翻页。
- 进入方式有两种：点总览右上角的「设置」；或者在菜单栏右键菜单里点「设置中心…」。从菜单进入时，面板直接打开在设置卡上。
- 标题行左边是「‹ 返回」胶囊，样式同「设置」按钮，后面隔 8pt 是「设置」标题。点「返回」回到总览。
- 内容区可以垂直滚动，滚动条用系统的悬浮样式，内容不超出时不显示滚动条。每行 30pt 高，行间有分割线：
  1. 「开机自启动」，右边是开关，控制 `SMAppService.mainApp`，就是原来菜单里那一项。
  2. 「版本」，右边是次要色的当前版本号，例如 `0.1.14`。
  3. 「更新」，右边是「检查更新」胶囊按钮，点了调起 Sparkle 检查，和菜单里的「检查更新…」是同一个动作。
- 从菜单打开设置卡时，面板一直开着，直到鼠标移进面板后又移出，或者点了面板外面。之后再悬停打开，仍然从总览开始。

## C3 右键菜单只留三项
- `检查更新…`，`设置中心…`，分割线，`退出栏况 ⌘Q`。
- 去掉灰色的电池状态行和「开机自启动」（开关挪到设置卡里）。
