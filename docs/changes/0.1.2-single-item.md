# 栏况 v0.1.2 契约：合并成一个菜单栏项

来源：老板 2026-11-18 23:22 真机反馈：目标是省菜单栏空间，必须聚合到一个图标里，不显示电池百分比。
样稿：`docs/changes/assets/0.1.2-single-item.png`（从左到右：充电中 / 接电未充 / 用电池 / 用电池 ≤20% / 无电池）。

## 菜单栏：只有一个 NSStatusItem
从左到右：电池图形 · 4pt 间距 · 两行文字。左右内边距各 4pt，总宽度目标 ≤ 48pt，硬上限 52pt。
- 电池图形：22×11pt（不含正极头），外框描边，内部填充宽度 = 电量 × 内宽。**不写百分比数字。**
  - 充电中：填充上以镂空方式叠 ⚡；接电未充（含已充满、优化充电）：叠插头；用电池：不叠标记。
  - 用电池且电量 ≤ 20%：填充用 systemRed；其余情况用模板色（跟随深浅菜单栏）。
  - 没有内部电池的 Mac：不画电池图形，也不留间距。
- 两行文字：字号 9pt、semibold、`monospacedDigit`，行高 10pt，两行整体在菜单栏里垂直居中，左对齐。
  - 上行内存「12G」（口径不变），下行 CPU「18%」（口径不变）。
  - 文字列宽按最长的「128G」「100%」固定，数值变化时项宽不变。
- 删除原来的第二个（电池）项和它的 autosaveName。

## 交互
- 悬停整个项：弹出原来的三行面板（内存、CPU、磁盘，加 0.1.1-panel-align 的环和对齐），离开缓冲 300ms 不变。
- 右键菜单第一行新增灰色、不可点的状态行：「电池 87% · 充电中 / 已接电源 / 使用电池」；没有电池的 Mac 不显示这一行和它下面的分隔线。其余菜单项不变。

## 验收
- S1：`menubar.png` 里只有一个栏况项；`--debug-longest`（128G / 100%）下测得项宽 ≤ 52pt，并写进 CI 日志。
- S2：XCTest 覆盖电池状态到图形的映射：充电中→⚡，接电未充→插头，用电池 20%→红色，21%→模板色，无电池→不画。
- S3：CI 用 `--debug-battery=<状态,电量>` 渲染 5 种状态的截图（CI 机器没有电池），和样稿对照：图形里没有数字，两行文字没有截断、没有重叠。
- S4：右键菜单第一行的状态文案正确，并且不可点。
- S5（老板真机）：从 v0.1.1 应用内升到 v0.1.2 后，菜单栏只剩一个栏况项，旧的电池项消失；关掉系统电池图标后，宽度比 v0.1.0 的两项明显更窄。

## 应用图标（能赶上就放进本版）
- 源图：`design/AppIcon-1024.png`（1024×1024，按 macOS 图标网格留好透明边距；源文件是 `design/icon.html` 里的 SVG）。用 `sips` 和 `iconutil` 生成 AppIcon.icns，写进 CFBundleIconFile。
- S6：Sparkle 的「已是最新版本」弹窗和访达里显示的是这张图标，不再是系统默认的空白图标。
