# 栏况 v0.1.12 契约：面板改成可滑动的卡片

来源：老板 2026-11-19 04:09，参考活动监视器底部的 CPU 和内存曲线。
样稿：`assets/0.1.12-cards-demo.html`（可滑动），截图 `assets/0.1.12-cards-2x.png`。

## 结构
- 卡片数 = 面板行数 + 1：第 1 张永远是「总览」（就是现在 0.1.11 的面板，一个像素都不改），后面依次是 内存、CPU、磁盘、网络、电池。没有电池的 Mac 不出电池卡（共 5 张）。
- 每次打开面板都从「总览」开始。
- 所有卡片同宽 260pt、同高（等于总览的高度），切换时面板大小不变。
- 底部是页码点：6pt 圆点，间距 6pt，当前页白色，其余 25% 白；点区高 14pt，下边距 6pt。只做指示，点了没反应。

## 切换
- 触摸板左右滑、鼠标滚轮上下滚都能切；一次手势只翻一张，0.25 秒缓动对齐。
- 不自动轮播，到第一张或最后一张就停，不循环。
- 鼠标在面板上滚动不要传给面板下面的窗口。

## 各卡片内容
- **内存**：标题行「内存」，右边 `13.4 / 16 G · 81%`。下面是已用比例曲线（绿色面积图，0–100%）。底行三项：已使用、已缓存、交换（`vm.swapusage`）。
- **CPU**：标题行右边是总占用。曲线照活动监视器：系统（红）在下，用户（蓝）叠在上面。底行三项：系统、用户、闲置，颜色和曲线一致。
- 曲线：最近 60 个点，跟菜单栏同一节奏每 2 秒采一次，所以面板没打开时也在攒历史，打开就有约 2 分钟的线。横轴最新的点在最右，从右往左长；纵轴固定 0–100%。睡眠时不采样，醒来接着画。
- **磁盘**：72pt 环形图（已用占比），右边三行：已用、可用、共。
- **网络**：不画曲线，24pt 大字两行 `↑ 6.4 KB/s`、`↓ 11 KB/s`，格式沿用面板网络行。
- **电池**：大电池图（填充按电量，充电时中间有 ⚡，低电量颜色沿用菜单栏规则），右边 24pt 大字电量，标题行右边是 `batteryStatusText`。

## 验收
- M1：测试覆盖卡片数（有电池 6、没电池 5）、翻页到头不越界、历史缓冲最多 60 个点。
- M2：CI 出每张卡片的 2x 截图，深色、浅色各一套；面板打开时 CPU 占用比 0.1.11 高不超过 0.5 个百分点，实测数写进日志。
- M4（老板真机）：触摸板和鼠标滚轮都能一张一张翻，总览和 0.1.11 一样。
