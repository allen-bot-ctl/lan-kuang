# 栏况 v0.1.7 契约：项内间距收紧、网速数字紧跟箭头

来源：老板 2026-11-19 02:25 截图，觉得栏况和旁边的间距不对。现状图：`docs/changes/assets/0.1.7-spacing-before.png`（2x）。
实测（2x 像素）：电池到 `13G` 9px，`89%` 到 `↑` 21px，`↑ 32K` 的箭头和数字中间空了一截。原因：每列按最长文案定宽，短值时空白留在列中间；网速列数字右对齐、箭头固定在左。PM 02:26 采纳。

## 布局（整项总宽不变，按最长文案定）
- 三段从左到右紧排：电池 · **3pt** · 内存/CPU 两行（左对齐）· **3pt** · 网速两行（左对齐）。
- 列间距从「列的定宽边界」改为**从这一列本次实际最宽那一行的右缘算起**。比如 `13G`/`89%` 实际宽于 `89%`，就从 `13G` 的右缘起算 3pt。整项宽度仍按最长文案固定，**多出来的空白全部放在整项最右边**，所以数字变化时整项不跳，只有右侧留白变化。
- 网速行：箭头（矢量细箭头）与数字间距 1pt，箭头和数字作为一体左对齐；上下两行的箭头左缘对齐。
- 左边距 2pt；右边距 = 2pt + 本次空出来的宽度。

## 验收
- S1：CI 出 1x 和 2x 图两组：最长（`128G/100%`、`↑999K/↓999K`）和短值（`13G/89%`、`↑32K/↓248K`）。
- S2：CI 日志打印各段实际间距：电池到文字、文字到箭头都在 3pt ±0.5pt；箭头到数字 1pt。
- S3：整项宽度在最长和短值下相同，≤ 76pt。
- S4（老板真机）：`↑` 紧贴数字；栏况看起来是一个整体，不像两个图标。
