# 栏况 0.1.17｜CPU 与内存用量警戒

## 验收

- C1：CPU 默认 80%，内存默认 90%，用现行显示的整数百分比。仅严格超过各自阈值标红；CPU 80% 不红、81% 红，内存 90% 不红、91% 红。CPU 41% / 内存 13 ÷ 16（显示 81%）时两项保持普通色；14 ÷ 16（显示 88%）也不红。把内存手动调到 80% 后，13 ÷ 16 只红内存；无内存总量时不告警。
- C2：菜单栏和总览只改变对应数值文字的颜色，详情卡片颜色不变。保留电池低电量、网速、磁盘的既有显示规则和采样频率。深浅外观下分别核对；相同文字和状态项宽度不应随颜色变化。
- C3：设置卡可独立调整 CPU、内存警戒阈值，0–100% 的整数。改完无需重启，按当前样本立即重算，应用重启与同 Bundle ID 升级后保留设置；100% 等于关闭该项警戒。
- C4：单测覆盖阈值等于/超过、截图示例、独立设置、边界、默认及存取；macOS CI 离屏验证正常、单行红、双行红及尺寸；真机再确认菜单栏、总览和设置页。
- C5：升级验收沿用 Sparkle。先确认稳定版已发布并验证 signed appcast 与 zip，然后在旧版点「检查更新」，核对版本、颜色、设置和持久化；仅编译/无发布 CI 不等于从旧版升级成功。

## 不做

不加通知、采样、图表、布局重做、更新机制或发布权限变更。
